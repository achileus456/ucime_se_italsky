# Fonty

Fonty jsou součástí repozitáře, aby aplikace nevolala externí servery (soukromí, offline provoz).

| Font | Autoři | Soubory |
|------|--------|---------|
| Playfair Display | Claus Eggers Sørensen | `playfair-*.woff2` |
| Nunito | Vernon Adams, Cyreal, Jacques Le Bailly | `nunito-*.woff2` |

Obě rodiny jsou licencovány pod **SIL Open Font License 1.1** (https://openfontlicense.org), která dovoluje volné použití, kopírování a redistribuci včetně komerčního využití. Soubory jsou podmnožiny `latin` a `latin-ext` (pokrývá českou diakritiku) stažené z Google Fonts.
